# Dataset provenance and integrity record / 数据来源与完整性记录

This file stores technical provenance details that are useful for reproducibility but unnecessarily interrupt the main manuscript. It does not grant redistribution rights for the raw archive.

本文件保存适合复现检查、但不适合放在论文正文中的数据来源与文件完整性信息。本文档不构成对原始牌谱的再分发授权。

## Confirmed from the supplied course material / 已由课程材料确认

- The source deck `国标麻将监督学习.pptx`, slide 3, identifies the records as self-play generated by the champion bot of the IJCAI 2020 Chinese Standard Mahjong competition.
- The deck reports 98,209 games and names three supplied files: `data.txt`, `sample.txt`, and `README.txt`.
- The supplied `README.txt` documents the event format and states that a match identifier can be viewed at `https://botzone.org.cn/match/<ID>`.
- The original course copy and the working copy used by this project are byte-identical:

```text
file: data.txt
bytes: 200348170
SHA-256: 2a95ba17a058fe3fbf2c240abbd3e05a88ee95a215cf8cb6c00ea4ff5193441b
records: 98209
```

The hash is an integrity identifier only. It is not evidence of ownership, licensing, or permission to redistribute the file.

## Public-source audit on 28 August 2026 / 2026 年 8 月 28 日公开来源检查

1. The [official IJCAI 2020 Botzone competition page](https://www.botzone.org.cn/static/gamecontest2020a_cn.html) links a human-player match dataset. That link is not described as the 98,209-game champion-bot self-play archive used here.
2. The official [`ailab-pku/Chinese-Standard-Mahjong`](https://github.com/ailab-pku/Chinese-Standard-Mahjong) repository publishes the judge, rules, fan-calculator usage, and sample bot, but its README does not publish this training archive.
3. A third-party Hugging Face mirror, [`Dannibal/ijcai-mahjong-moyu-binaries-public`](https://huggingface.co/datasets/Dannibal/ijcai-mahjong-moyu-binaries-public), publicly exposes a dataset described as `data.txt` with 98,209 records and displays a format description matching the supplied README. However, the mirror is not operated by the original course or dataset provider, labels its license only as `other`, and states that it was made public because private-storage quota was unavailable.
4. A second third-party Hugging Face entry, [`gjxstc/chinese-standard-mahjong-data`](https://huggingface.co/datasets/gjxstc/chinese-standard-mahjong-data), is publicly visible and labels its contents MIT, but its dataset card does not establish the origin or authorization of the underlying raw records.

These findings confirm public accessibility of apparent copies, not authoritative publication or redistribution permission.
