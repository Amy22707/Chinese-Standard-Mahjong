# Base-E17

Last checkpoint of the shared base run. It corresponds to checkpoint index 17 and validation epoch 18 (loss 0.3487, policy accuracy 0.8693). It was the old competition candidate and the initialization checkpoint for outcome-weighted continuation.

## 中文

这是同一条基础训练的最后一个 checkpoint，对应 checkpoint 17 和第 18 次验证：验证损失为 0.3487，策略准确率为 0.8693。它曾是旧的比赛候选模型，也是后续 outcome-weighted 继续训练的初始化 checkpoint。它与 Base-E16 相邻，并非独立训练所得。
