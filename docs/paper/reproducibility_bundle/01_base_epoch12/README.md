# Base-E12

Checkpoint index 12 from the shared 18-validation base supervised run. It corresponds to validation epoch 13 (loss 0.3671, policy accuracy 0.8617) and is retained for checkpoint-selection and local-opponent sensitivity experiments.

## 中文

这是同一条基础监督训练轨迹中的 checkpoint 12，对应第 13 次验证：验证损失为 0.3671，策略准确率为 0.8617。论文仅将它作为较早训练阶段的代表，用于 checkpoint 选择曲线和本地对手敏感性实验；它不是独立随机种子训练出的模型。
